## Notes

- **Helpers:** `type-als-prior-art`, read-only source/ALS evidence completed; `dp11-packet-evidence`, read-only D2/brief requirements matrix completed. Both returned text-only results with no source edits.
- **Status:** `decided: DP-11`. Chose a curried, package-internal overloaded `compileGuardPlan<Input, Seed>()` returning one opaque `CompiledGuard<Input, Seed, Final>`; guard additions infer as objects and merge in D2 order. `override` starts from `Seed`; `"public"` returns exactly `Seed`.
- **Selected helpers:** `allow()` and `allow<const Added extends object>(locals)` return the D2 allow shape; `deny(denial: Denial)` returns the D2 denial shape. No locals shape is broad-asserted into the callback object.
- **Selected scope signature:** `InvocationScope` gains required `metadata: { source: "local" | "http"; surface: Surface }` and `signal: AbortSignal`. Inputs, locals, caller, `NameView`, env and headers stay on `InvocationContext`/`InvocationBase`, not ALS.
- **Compatibility:** this is incompatible with scope v1 because required scope fields may be read by a newer copy while an older copy supplies the same global ALS store. Bump `INVOCATION_SCOPE_VERSION` from `1` to `2`; retain the same global process-patch contract and fail fast on version mismatch.
- **Anti-widening:** `AddedLocals<G>` is extracted from the concrete guard result, then `SafeGuard<G>` rejects `IsAny<AddedLocals<G>>`; the internal declaration/bind boundary extracts the concrete handler parameter and rejects `any`/`unknown` before matching `InvocationContext<Input, Final>`. Positive type evidence therefore cannot silently collapse to a broad locals bag.
- **Strict spike:** final sanitized command `node_modules/.bin/tsc --ignoreConfig --noEmit --strict --target ES2023 --module NodeNext --moduleResolution NodeNext --skipLibCheck .tmp/dp11-spike.ts` exited `0`. Positive cases compiled for seed → caller → workspace, override, public, boolean and denial. `@ts-expect-error` proved missing locals, override/public removal, any guard additions, and any/unknown handler contexts fail.
