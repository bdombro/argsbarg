## Notes

- **Status:** `decided: DP-20`. Applied the complete outcome only to task 20's `## Brief`; no source/runtime,
  map, contract, template, docs or consumer file changed.
- **Helpers:** none, because the configured helper/decider model chain is unavailable in this host's delegator
  and the task permits helpers only when available. All required reads stayed local and read-only.
- **Selected A:** public `command()` and runnable-root handlers receive
  `InvocationContext<flat parsed inputs, Locals>` directly. Path params merge into `inputs`; raw parser,
  `CommandContext`, response and transport conveniences do not enter the handler boundary. A has no
  `any`/`unknown` widening and preserves D2's same guard/handler object.
- **Compatibility:** `App.invoke(argv)` becomes the non-exiting native CLI path. During the unreleased 21/23
  transition only, its exact explicit HTTP/MCP options branch remains marked legacy, still calls `invokeBound`
  once and invokes the same A-typed declaration. The post-adapter owner removes that branch, `response`,
  `CommandContext` and related exports before release; no 8.x shim or migration guide ships.
- **Hooks/errors:** `beforeInvoke` runs after coercive binding and before the sole Zod parse, mutating only the
  base `locals`; `invokeBound` copies it, then guards and handler share the same final context. `afterInvoke`
  observes only `ok`; invalid/error run `formatError` then `onError`; denial is encoded directly without passing
  through exception hooks. Bind failure runs no guard, handler or `beforeInvoke`.
- **No-schema typing:** `src/core/zod-schema.ts` becomes the sole runtime-Zod owner. It synthesizes a strict
  schema from ancestor/leaf options, positionals and path params, and composes it with authored input/path
  schemas for one `invokeBound` parse. Coercion stays in the binder; emitted JSON Schema remains discovery-only.
- **Guard scope:** task 20 registers an empty compiled CLI plan with seed `Locals`. No public CLI/default or
  operation guard is added. The later shared surface/factory public API owner adds guard declarations once all
  surfaces can consume the same D2/DP-11 contract.
