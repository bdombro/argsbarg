# 91. Decide v9 child composition API

## Contract rev 1

- Decide the exact build-time keyed child descriptor, namespace behavior, scoped env/header views, guard propagation, collision errors and transport exposure policy.
- Keep one parent executable and remove runtime gateway loading; do not add runtime child lifecycle.
- Name exact implementation files, public exports, examples/docs impact and focused tests.
- Read-only decision only; no source edits, tests, network or runtime host work.
- Write `decisions/D91.md` and task Notes.

## Notes

- **Status:** ✅ accepted as D91.
- **Decision pointer:** [D91 — Build-time keyed child composition](../decisions/D91.md)
  fixes `children: { key: { app, expose? } }`, nested namespace paths, derived
  env/header prefixes, preserved child guard/hook plans, fixed exposure and
  startup collision failures.
- **Public behavior:** child declarations join the parent's fixed CLI/REST/RPC/
  MCP catalogs. CLI uses key path segments, REST uses `/key/path` plus
  `key__operationId`, RPC uses `key.method`, and MCP uses `key__tool`. Local
  child env/header views expose only derived prefixes and never fall back to
  unprefixed, sibling or opposite-source values.
- **Guard boundary:** parent transport/mount admission may seed fresh locals,
  then the child's existing surface and operation plan runs. Parent surface
  guards/hooks do not wrap child operations, and child `run()`/listeners/
  lifecycle are never used. Future task follow-ups must reconstruct the scoped
  source and rerun child policy from the current request.
- **Implementation handoff:** D91 names the public types, `src/runtime/children.ts`,
  factory/export integration, narrow adapter registration clones, focused
  child/factory/lifecycle tests, and exact README/docs/changelog updates. No
  runtime gateway loader or template capability change is required.
- **Validation for this decision task:** read-only repository and plan evidence
  only. No source/test edit, test/build, network, host, install, commit, push or
  release operation was used. `D91.md` and these Notes are the only owned edits.
