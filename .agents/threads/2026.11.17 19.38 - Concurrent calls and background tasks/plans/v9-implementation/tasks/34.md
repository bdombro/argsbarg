- **Selected mount:** one `HttpMount` owns flat `{ kind: "exact" | "prefix", path }` claims plus `handle(request, context)`. Paths are normalized; duplicate/overlapping claims fail before bind; method and protocol behavior stay in the adapter. `HttpMountContext` contains only the exact request `AbortSignal`. No fallback middleware, Node stream, logger, `ServerRuntime` or caller/guard policy enters the listener.
- **Selected bind:** normalized `{ kind: "tcp", host, port } | { kind: "unix", path }`; TCP ports permit `0`, Unix is in the first slice and uses absolute normalized paths. `ResolvedHttpServeConfig.targets` is the non-empty resolved boundary. All claims/targets validate first, endpoints bind serially behind one shared barrier, and failure closes acquired binds in reverse order while preserving the original error.
- **Selected handle/lifecycle:** frozen `addresses`, readonly live `state: running | draining | forcing | closed | failed`, shared `terminal: Promise<void>` and memoized `stop({ forceAfterMs? })`. First `stop` wins; later calls return the same promise. It transitions `running → draining`, then `draining → closed` or `draining → forcing → closed` after `10_000ms` by default. Force aborts only remaining transport request controllers, cancels readers and destroys remaining connections; it does not touch durable app jobs. Unexpected endpoint close/error transitions to `failed` and rejects `terminal`.
- **Unix ownership:** after successful bind, private evidence records normalized path plus `lstat` `dev`/`ino`. Cleanup unlinks only an identity match; `ENOENT` is clean and a foreign replacement is preserved. A failed bind or unverified identity never triggers unlink.
- **Why:** this is the smallest contract that represents the fixed mounts, keeps D2 in adapters, gives all binds an atomic startup barrier, and leaves one owner for the race-prone stop/force transition. The handle is app-lifecycle-neutral and preserves Node/Web streaming without introducing a server framework.
