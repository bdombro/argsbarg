# 90. Decide v9 guard and caller public APIs

## Contract rev 1

- Decide exact author-facing CLI and MCP surface/operation guard declarations within settled D2/DP-20.
- Define how MCP HTTP verifies/establishes required caller and passes a typed seed into the registry dispatcher; stdio/local use the exclusive local source.
- Name exact task-36-adjacent public and internal files and focused acceptance checks; keep REST/RPC behavior fixed.
- Read-only decision only; no source edits, tests, network, host validation or credentials.
- Write `decisions/D90.md` and task Notes.

## Notes

### Decider outcome (2026-11-20)

- **Decision:** `decisions/D90.md` is accepted.
- **Public guards:** preserve DP-20's root CLI shape; add `cli.guard` plus
  command `guard`, and `mcp.guard` plus tool `guard`. All use D2's existing
  supplement, `{ mode: "override", run }`, and `"public"` composition.
- **Path semantics:** CLI policy applies only to authored CLI leaves. Generated
  `api`, `rpc` and `mcp call` run their target surface plan; relay performs no
  local guards and has no fallback.
- **Caller seed:** expose one `mcp.http.middleware` API. It returns
  `{ kind: "next", locals }` or `{ kind: "respond", response }`, verifies only
  HTTP headers and passes fresh locals into `InvocationBase`. Remove
  `admission`/`admit` aliases. Do not add public stdio/local seed APIs;
  protected local paths establish caller through `mcp.guard`/tool guard from
  the exclusive env source.
- **MCP denial handoff:** preserve the D2 `InvocationOutcome` alongside the
  encoded MCP response. HTTP denials with `http`/`challenge` metadata become a
  native pre-SSE HTTP response; stdio/local retain the native MCP tool-error
  envelope. REST/RPC behavior remains fixed.
- **Implementation ownership:** D90 defines three serialized slices for
  CLI registration, MCP declaration/seed wiring, and task-35 public
  docs/exports integration. Exact owned source and focused test files are in
  the decision.
- **Evidence/limits:** read-only repository, plan and source inspection only.
  No source/tests/network/host validation was used.
